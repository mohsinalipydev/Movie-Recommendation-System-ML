# 🎬 Movie Recommendation System

A machine learning-powered movie recommendation system that combines **Content-Based Filtering** and **Collaborative Filtering** into a single **Hybrid Recommender**, served through a custom **HTML/CSS/JavaScript** web interface with live movie posters — all trainable and runnable directly from **Google Colab** and shared instantly via **ngrok**.


---

## Short Description

> A hybrid movie recommender (content-based + collaborative filtering/SVD) trained on TMDB & MovieLens datasets from Kaggle, served through a custom HTML/CSS/JS web app with live TMDB poster images, running directly from Google Colab via ngrok.

---

## Features

- **Content-Based Filtering** — recommends movies with similar genres, cast, director, and plot keywords using **TF-IDF** + **Cosine Similarity**.
- **Collaborative Filtering** — learns from user rating patterns using **SVD (matrix factorization)** via the `surprise` library.
- **Hybrid Scoring Engine** — combines both techniques with an adjustable weight, giving more personalized and accurate results than either method alone.
- **Custom Web Interface** — built from scratch with plain **HTML, CSS, and JavaScript** (no frontend framework), with:
  - Searchable movie autocomplete
  - Adjustable User ID, result count, and content/collaborative weight slider
  - Responsive movie poster grid
- **Live Poster Images** — fetched in real time from the **TMDB API**.
- **One-Click Public Demo** — Flask backend exposed publicly using **ngrok**, no deployment/hosting needed.
- **Fully Reproducible** — runs end-to-end inside a single Google Colab notebook, from raw Kaggle data to a live web app.

## How It Works

```
┌─────────────────┐     ┌──────────────────────┐
│  TMDB 5000       │     │   MovieLens Ratings   │
│  (movies+credits)│     │   (userId, movieId,   │
│                  │     │    rating)            │
└────────┬─────────┘     └──────────┬───────────┘
         │                          │
         ▼                          ▼
┌──────────────────┐      ┌──────────────────────┐
│ Content-Based     │      │ Collaborative        │
│ Filtering         │      │ Filtering (SVD)       │
│ TF-IDF + Cosine   │      │ Matrix Factorization  │
│ Similarity        │      │                       │
└────────┬──────────┘      └──────────┬───────────┘
         │                            │
         └───────────┬────────────────┘
                      ▼
            ┌───────────────────┐
            │  Hybrid Recommender │
            │  (weighted score)   │
            └─────────┬───────────┘
                       ▼
            ┌───────────────────────┐
            │ Flask API (/api/*)     │
            └─────────┬─────────────┘
                       ▼
        ┌───────────────────────────────┐
        │ HTML + CSS + JS Frontend       │
        │ (posters from TMDB API)        │
        └───────────────────────────────┘
                       ▼
              🌐 Public URL via ngrok
```

**Pipeline steps:**
1. Download **TMDB 5000 Movie Dataset** and **MovieLens Small Dataset** from Kaggle.
2. Merge movie metadata (genres, keywords, cast, director, overview) into a single "tags" field.
3. Vectorize tags with **TF-IDF** and compute pairwise **cosine similarity** between all movies.
4. Train an **SVD** model on user ratings to predict how a specific user would rate a movie.
5. For a chosen movie + user, blend the content similarity score and the predicted rating into a single **hybrid score**.
6. Serve results through a **Flask** API, which also fetches poster images from **TMDB**.
7. Render everything in a hand-built **HTML/CSS/JS** interface, exposed publicly through **ngrok**.

## Getting Started

### Prerequisites (all free)

You'll need three API keys/tokens before running the notebook:

1. **Kaggle API Token** — to download the datasets
   - Kaggle → Settings → API → *Create New Token*
2. **TMDB API Key** — to fetch movie poster images
   - [themoviedb.org](https://www.themoviedb.org) → Settings → API → *Request an API Key* (Developer)
3. **ngrok Authtoken** — to expose the local Flask app publicly
   - [ngrok.com](https://dashboard.ngrok.com/signup) → Your Authtoken

### Run the Project

1. Open `Hybrid_Movie_Recommendation_System.ipynb` in **Google Colab**
2. Run the cells **in order, from top to bottom**
3. When prompted, paste your Kaggle token, TMDB API key, and ngrok authtoken (inputs are hidden/secret)
4. At the end, a **public ngrok URL** will be printed — open it in your browser
5. Search for a movie, adjust the user ID / weight slider, and click **Recommend**

### Stopping the App

Run the final cell in the notebook, or manually:

```python
ngrok.kill()
flask_process.terminate()
```

## API Endpoints (Flask backend)

| Endpoint | Method | Description |
|---|---|---|
| `/` | GET | Serves the main HTML interface |
| `/api/movies` | GET | Returns list of all movie titles (for search/autocomplete) |
| `/api/recommend` | GET | Returns hybrid recommendations. Query params: `movie`, `user_id`, `n`, `weight` |

Example:
```
GET /api/recommend?movie=Avatar&user_id=1&n=10&weight=0.5
```

## Hybrid Scoring Formula

```
hybrid_score = (content_weight × content_similarity) + (collaborative_weight × predicted_rating)
```

- `content_weight + collaborative_weight = 1`
- Adjustable live from the interface using the weight slider
- Falls back to a movie's average TMDB rating when no collaborative data is available for that user/movie pair
